# Skill provenance

The public repository's THIRD_PARTY.md records exact upstream commits, license
locations, and integration modifications. Every vendored specialist carries its
own LICENSE. The router and rendering helpers are maintained by this repository.

Use `/skill telegram-visual-brief` for explicit routing. Telegram installations
that expose normalized skill commands may also support `/telegram_visual_brief`,
`/build_dashboard`, `/baoyu_design`, and `/d3_viz`. Check actual discovery before
assuming slash commands are registered.

Update through a reviewed repository revision and installer preview; preserve
local modifications and rerun rendering validation after changes.
