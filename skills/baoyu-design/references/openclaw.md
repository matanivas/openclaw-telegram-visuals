# OpenClaw adapter

Use available file/shell tools to create the design. Ask material questions in
the current chat and use the supplied brief for other choices. Preview with the
installed browser tool, or render locally with Playwright and inspect images.
A local HTTP URL is only reachable on the host unless remote access is configured.

For Telegram, return to the sibling `telegram-visual-brief` skill for phone-sized
export, inspection, format selection, and the actual message-tool send. This
contract takes precedence over generic local URL/HTML-attachment instructions.
Preserve the interactive source locally.

Optional Figma, Canva, image-generation, and other external integrations are used
only when requested and available. They are not required for local prototypes.
If subagent tools are unavailable, do verification in the owning agent.
